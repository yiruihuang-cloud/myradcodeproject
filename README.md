# Game Music with Code
## Project overview
This project is a prototype of a game inspired musical composition created with TunePad and Python. The piece consists of 3 coded tracks: drums, piano melody and bass. All tracks are set in the same general form: Intro, Main, Build-up, Climax, Ending. The aim of the project is to investigate the use of programming concepts including variables, lists, functions, loops and conditions to organise and develop a music.
## Files
drums.py – drum track code

piano.py – piano melody code

bass.py – bass track code

tunepad_project_133705.json – exported TunePad project file
## How to Run
1. Open TunePad
2. Create drum, piano and bass tracks
3. Copy the code from each .py file into the corresponding track.
4. Set the tempo to 120 BPM and the time signature to 4/4.
5. Run all three tracks together.
